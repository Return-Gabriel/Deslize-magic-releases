# Deslize Magic

**Dê vida ao seu Apple Magic Mouse no Windows: rolagem suave, autoscroll, gestos e cliques do seu jeito.**
Gratuito · Português · Windows 10/11 · Feito pela GhostDev

## 📥 Download

**[⬇️ Baixar a última versão](https://github.com/Return-Gabriel/Deslize-magic-releases/releases/latest)** — baixe o `DeslizeMagic.exe` e execute. É um arquivo único: não precisa instalar nada, nem ser administrador.

- Funciona no **Windows 10 e 11 (64 bits)**.
- Precisa do **driver gratuito da Apple** (Boot Camp) para a rolagem do Magic Mouse funcionar. O próprio app avisa se ele estiver faltando e mostra como instalar.

> Como o app ainda não tem assinatura digital, o Windows pode mostrar um aviso (SmartScreen) na primeira vez. Clique em **Mais informações → Executar assim mesmo**.

O Deslize Magic avisa quando há uma versão nova e se atualiza com um clique, no botão **Procurar atualizações**.

## ✨ Recursos

- **Rolagem suave:** rolagem fluida, com velocidade, direção e aceleração ajustáveis.
- **Autoscroll:** segure a tecla e clique, mova o mouse para rolar sozinho — como a rodinha dos mouses comuns. Clique de novo para parar.
- **Voltar e avançar:** deslize o dedo para os lados para navegar entre as páginas.
- **Trocar de área de trabalho:** deslize de lado para alternar os desktops do Windows.
- **Cliques do seu jeito:** troque esquerdo e direito e configure o clique do meio.
- **Velocidade do ponteiro:** ajuste o cursor sem sair do app.
- **Conforto:** fica perto do relógio, inicia com o Windows e lembra todos os seus ajustes.
- **Só o seu mouse:** aplica os ajustes apenas ao Magic Mouse — ou a qualquer mouse, se você preferir.

## 🖱️ Gestos e atalhos

| Ação | Como fazer |
|---|---|
| Voltar / avançar página | Deslizar o dedo para a **esquerda** / **direita** |
| Trocar de área de trabalho | Deslizar o dedo para os lados (no modo "áreas de trabalho") |
| Autoscroll | Segurar **Alt** + clique e mover o mouse; clicar de novo para parar |
| Clique do meio | **Ctrl** + clique (tecla configurável) |
| Rolar na horizontal | Deslizar o dedo para os lados (no modo "rolagem") |

## 🔄 Atualizações automáticas

O app verifica esta página de releases, compara com a versão instalada e, se houver uma mais nova, baixa e se atualiza sozinho — sem reinstalar nada.

## 🔒 Privacidade

Nenhum dado pessoal sai do seu computador. Os ajustes ficam guardados só na sua máquina.
